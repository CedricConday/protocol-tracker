# Sidelined for the "pure tracker" scale-back (2026-07-01)

These are the ORIGINAL files, parked here (not deleted) while the app is scaled
back to a pure tracker that gives no medical advice/info — the user enters
everything themselves. Restore any of these if we cut too far.

- `seed.original.ts` — pre-loaded protocol (the first user's real Dr. Worms stack),
  supplement interaction warnings, awareness dates, dietary "forbidden" list.
- `diseaseProfiles.original.ts` — per-disease recommended D3 doses, doctor notes, medical descriptions.
- `foodPairings.original.ts` — supplement/food pairing + absorption tips.
- `awarenessData.original.ts` — health awareness messages.

The live versions at the original paths are neutralized stubs (empty / names-only).
