# Protocol Tracker — How to install it (free, 2 minutes)

Protocol Tracker is **free**. There's no App Store fee yet — so for now you run it
through a free helper app called **Expo Go**. It works the same on iPhone and Android.

> If you like it and it helps, sharing or supporting the project is what funds the
> next version (a one-tap install straight from the App Store / Play Store).

   **[ QR CODE HERE — paste after publishing ]**

3. Protocol Tracker opens.
4. When it asks about **notifications**, tap **Allow**.

## Every day
- Open the app and tap **Start My Day** when you take your first dose — the app
  schedules the rest of the day's reminders from that moment (it follows *you*, not a
  fixed clock).
- Your data stays **only on your phone**, encrypted. Nothing is uploaded.

## If a reminder is silent
- Check your phone isn't on silent / Do Not Disturb.
- iPhone: Settings → Notifications → Expo Go → Sounds **on**.
- Android: the reminder uses a high-priority channel, so sound should be on by default.
